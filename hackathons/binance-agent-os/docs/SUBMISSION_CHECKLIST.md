- Follow `@Binance` on X.
- Repost the official hackathon announcement.
- Reply or quote-repost with the demo and this GitHub repository.
- Complete the official survey before the deadline.

## Repository review standard

- Video contains no email, balance, order, token, API key, local path, or private account data.
- Both MCP names and connected states are visible.
- The demo clearly attributes live market data to Binance Agent OS.
- The demo clearly attributes analysis and strategy handoff to PREX.
- No claim says PREX MCP executed a trade.
- GitHub repository is public and all links work in a logged-out browser.
